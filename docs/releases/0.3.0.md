# Linux Supply Chain Guard 0.3.0 — PHP readiness

This release adds a default, read-only PHP readiness inventory so operators can
find PHP evidence before applying the forthcoming security update.

**PHP patch status remains unknown.** The October 20 advance notice schedules a
security release for October 21, 2026 at 14:00 UTC, possibly earlier. Affected
and fixed versions were not disclosed in that notice. This tool does not patch
PHP, establish runtime exploitability, detect exploitation or certify that a
serving deployment has loaded an update.

- [Official PHP notice](https://www.php.net/archive/2026.php)
- [PHP readiness scope and usage](../php-readiness.md)
- [OX research updates](https://www.ox.security/blog/) — general blog index;
  no PHP-specific OX article was verified for the October 20 snapshot.

## PHP inventory

- Installed Debian/Ubuntu and Alpine package records, preserving full vendor
  revisions; removed packages are ignored and held installed packages retained.
- Common CLI, CGI and FPM binary paths, PHP configuration paths and Apache PHP
  module configuration. No binaries are executed or configuration contents read.
- Composer PHP requirements/platform overrides and supported official PHP image
  declarations in Dockerfiles, Containerfiles and block-style Compose files.
  These are declaration leads, not evidence of a running deployment.
- Explicitly selected symlinked snapshot roots work; discovered links beneath
  the root remain unfollowed. Exclusions and inspection limits remain enforced.

JSON includes `phpReadiness` and its coverage details. Text output always states
the unknown PHP patch status. PHP evidence produces review findings. Incomplete
PHP inspection makes aggregate coverage incomplete and can produce exit code 3.
Existing precedence remains 4 > 2 > 3 > 1 > 0. Operators may therefore see new
review or incomplete results on hosts that previously returned zero.

## Other changes since 0.2.0

This release also includes the previously reviewed October metadata checks for
MALFEX/Apex campaign leads, fake-font task behavior, Airflow SSH/SFTP provider
pins, Harbor image versions, and Debian curl/AnyDesk package posture. Vendor
backports and live reachability remain unverified. Metadata scope notices and
Tensorlake inspection limits were refined, and release/CI package scanning was
hardened against scanner shadowing. See the README for each rule's limits.

## Verification and download

The full test suite and PHP root-link regressions are required to pass before
publication, along with the exact outgoing-range and packed-artifact Push Guard
checks. Release assets include the npm-format tarball and its SHA-256 manifest.

This is a GitHub release. npm registry publication is separate; use the attached
`linux-supply-chain-guard-0.3.0.tgz` download for this release.

```sh
sha256sum --check SHA256SUMS
npm install --global ./linux-supply-chain-guard-0.3.0.tgz --ignore-scripts
```

The scanner remains read-only. Its dated advisory is not a live feed. Consult
PHP and distribution or hosting-provider advisories when the patch is released.
