# Linux Supply Chain Guard 0.4.1 — web review reporting corrections

Upgrade from 0.4.0 and rerun scans performed without usable `/proc/self/fd`
access, including minimal containers or chroots. Version 0.4.0 could skip
existing web configuration files while reporting complete coverage and
returning exit code 0. Its empty result in that environment is not reliable.

## Corrections

- Validate the procfs descriptor anchor against the opened root directory.
  Missing, inaccessible or mismatched anchors now produce
  `descriptor-anchor-unavailable`, incomplete coverage and exit code 3,
  subject to the existing higher-priority exit codes. An anchor that
  disappears during optional-path discovery is also reported as incomplete.
- Compare webroot content and Unix permissions independently. A file changed
  in both ways now produces both `webroot-content-changed` and
  `webroot-permissions-changed`; finding limits still make comparison incomplete.

These address the [P1 coverage finding](https://github.com/Dragon-Lady/linux-supply-chain-guard/pull/5#discussion_r4331823536)
and [P2 permissions finding](https://github.com/Dragon-Lady/linux-supply-chain-guard/pull/5#discussion_r4331823542)
reported after 0.4.0 was released. See the
[supported configurations and baseline workflow](https://github.com/Dragon-Lady/linux-supply-chain-guard/blob/v0.4.1/docs/web-exposure.md).

## Verification

Six added regression cases cover unavailable or lost descriptor access,
anchor identity mismatch, incomplete webroot manifests, simultaneous content
and mode changes, finding limits and CLI output/exit behavior. The failures
were reproduced on the 0.4.0 source before repair. Missing procfs was simulated
with filesystem error injection, not a live chroot experiment.

The full test suite, package checks and Push Guard are release gates.

## Scope and download

The checks remain read-only. Runtime exposure and PHP patch status remain
**unknown**. This corrects the checker; it is not a PHP security patch and
does not establish internet exposure or compromise. Follow the
[PHP project notice](https://www.php.net/archive/2026.php) and
[OX Security updates](https://www.ox.security/blog/) for further information.

Download the tarball and checksum manifest from this GitHub release, then run:

```sh
sha256sum --check SHA256SUMS
npm install --global ./linux-supply-chain-guard-0.4.1.tgz --ignore-scripts
```

npm registry publication remains a separate gated operation.
